## Muaz Furkan Kılıç

I build AI systems for the energy sector. İstanbul.

Most of my work is forecasting and document understanding. On the forecasting side that
means ensemble models predicting generation for wind and solar plants, where being
confidently wrong costs real money and the weather has no respect for your validation
split. On the document side, LLM-based extraction pipelines that read unstructured
paperwork and pull out the fields a person would otherwise retype by hand.

The rest is plumbing of the useful kind: a pricing engine, automatic classification and
routing for incoming requests, and agent systems built with LangGraph and n8n. I also
hold a Product Owner role on one of our teams, which has mostly taught me how much of
engineering is deciding what not to build.

About two and a half years in, heading deliberately toward AI and agentic engineering.

### Stack

Python · LangGraph · LangChain · n8n · PyTorch · scikit-learn · FastAPI · Docker ·
PostgreSQL · Java / Spring Boot · TypeScript / Angular

### What's here

Not much, honestly. The professional work lives in private repositories, so this profile
is mostly an archive of university coursework from 2022-2023. I've kept it up rather than
quietly deleting it — partly because editing your own history is a bit revisionist, and
partly because some of it contains instructive failures I'd rather document than hide.

- **[ml-coursework](https://github.com/muazfurkan/ml-coursework)** — eight ML assignments
  collected into one repository: GANs, GRUs, autoencoders, dimensionality reduction. The
  READMEs say which models didn't work and why, which is the only part still worth reading.
- **[infomanager-backend](https://github.com/muazfurkan/infomanager-backend)** ·
  **[infomanager-frontend](https://github.com/muazfurkan/infomanager-frontend)** — a
  Spring Boot + Angular CRUD application from a 2022 internship.
- **[DropboxCryptor](https://github.com/muazfurkan/DropboxCryptor)** — AES-encrypted
  Dropbox client with post-download integrity checking. 2022.
